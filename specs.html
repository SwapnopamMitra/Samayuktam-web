1. SPCMP (Float32 Container & Canonicalization)

The Problem

IEEE-754 binary32 values diverge across heterogeneous hardware due to NaN payloads, signed zeros, and FMA rounding differences.

The Solution

SPCMP is a reversible float32 container format that enforces a deterministic total order.

  • Canonicalization: All NaN payloads collapse to 0x7FC00000. -0.0 collapses to +0.0. All other floats remain bit-exact.
  • Ordering: Bijective mapping to uint32 for unsigned comparison.
  • Compression: Order-0/1/2 predictive delta transform followed by Zstandard.
  • Verification: Fail-closed SHA-256 Merkle root over the uncompressed predictive stream.

The 4 Commands

./spcmp
# 1. Sort and compress the original array
./spcmp sort input.bin

# 2. Verify the Merkle commitment
python3 verify.py input.sorted.pcmp --info

# 3. Reconstruct the original array
./spcmp unsort input

# 4. Compare for byte-for-byte lossless recovery
cmp input.bin input.unsorted.bin

2. CAGM (Deterministic ML Training)

The Problem

Standard ML training pipelines rely on floating-point math, meaning the exact same dataset and hyperparameters will produce different model weights depending on the GPU or CPU used.

The Solution

CAGM is a fixed-point integer classifier (Q16.16) that completely removes floating-point arithmetic from the training loop.

  • The Integrity Engine (IE): Canonicalizes logits at layer boundaries to ensure bit-exact hashes across compilers and hardware.
  • Trajectory Proof: Emits a 64-character SHA-256 proof that binds the weights, gradients, activations, and epoch order into a single cryptographic commitment.
  • Output Contract: Strict stdout output: accuracy, proof, and ie_verify.
