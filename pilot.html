1. What You Get

The pilot is a fully functional, cryptographically bound evaluation of the Samayuktam stack. It is not a SaaS subscription. It is a local binary that proves the architecture works on your specific hardware.

  • Online-Verified: Every run performs an HTTPS round-trip to our licensing server to verify use count. No offline mode.
  • Full Output: Generates the actual Merkle roots, canonicalized .pcmp files, and CAGM SHA-256 training proofs.

3. How to Get Bound (The Handshake)

To request a pilot, you do not fill out a form. You email us the hardware fingerprint of the machine you intend to test.

hardware fingerprint · run all four
# 01 · Machine ID
cat /etc/machine-id
# Persistent OS-level machine identifier.

# 02 · MAC address
ip link show | grep "link/ether" | awk '{print $2}' | head -1
# Primary NIC hardware address.

# 03 · CPU model
grep "model name" /proc/cpuinfo | head -1 | cut -d: -f2 | xargs
# CPU model name from /proc/cpuinfo.

# 04 · CPU physical ID
grep "physical id" /proc/cpuinfo | head -1 | cut -d: -f2 | xargs
# Physical socket ID from /proc/cpuinfo.

Send all four values to: swapnopam@samayuktam.com

4. Technical Constraints (Read Before Applying)

  • Linux Only: Requires a live internet connection on every run.
  • Supported Environments: WSL2 and Google Colab are supported for single-session evaluation.
  • Unsupported Environments: Snapshot/revert-style VMs (VirtualBox, VMware) are not supported, as reverting a snapshot breaks the fingerprint assumption by design. Ephemeral runtimes that change MAC/Machine ID will fail the check.
  • Evaluation is under mutual NDA. The core method and internal constants remain sealed.
